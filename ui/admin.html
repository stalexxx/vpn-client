ШАГ 1 ИЗ 3

Установка 3x-ui и токен

Ключ из ~/.ssh (с парным .pub). Приложение не читает приватный ключ: на сервер уходит только публичный. Ключ должен быть без пароля или загружен в ssh-agent.

Пароль используется только для этой установки и нигде не сохраняется. Ключ нужен, чтобы приложение потом управляло панелью через SSH-туннель, а он работает только по ключу. Ключ сервера запоминается при первом подключении; если он изменится, подключение будет отклонено.

Подключение по системному SSH-ключу. Цель должна быть доступна и добавлена в known_hosts.

Сохраните данные самостоятельно. Приложение не сохраняет логин и пароль на диск.
API-токен получен автоматически.

  
Выберите существующий inbound или создайте VLESS + XHTTP + TLS. Для сертификата используется ACME; домен должен указывать на сервер, а порт 80 быть доступен из интернета.
Для сервера с IP-адресом домен вида 1-2-3-4.sslip.io подставляется автоматически; его можно заменить своим.
Сертификат сохраняется в /root/cert/<домен>/fullchain.pem и privkey.pem, как в SSL-менеджере 3x-ui.

  
Клиент будет создан в выбранном inbound-е и добавлен в сохранённый кэш после завершения мастера.
Без этого сайты вроде ipify видят адрес вашего сервера. WARP включается при нажатии «Готово» (около 20–40 секунд); если не получится, установка не отменяется, а WARP можно включить позже в настройках сервера. У Cloudflare WARP возможны капчи на некоторых сайтах.
